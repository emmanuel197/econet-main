# Wiki rules — read once, then read `index.md`

Work knowledge for the WONA web client: briefs, API findings, decisions, what was built.
Not a tutorial — no teaching or concept explanations here.

1. **Read `index.md` first** and load only the 2–3 pages you need.
2. **Update pages incrementally**; add a dated line to `log.md` for each unit of work.
3. **`raw/` is immutable** (verbatim sources). Distil facts into `pages/`.
4. **Contradictions:** mark the old claim `🪦 STALE` beside the new one with source + date; don't silently overwrite.

Confidence tags: `✅ VERIFIED` (checked in code or live) · `🔶 LIKELY` · `⚠️ ASSUMPTION` ·
`❓ NEEDS-CLARIFICATION` (also list in `pages/open-questions.md`) · `🔗 EXTERNAL` · `🪦 STALE`.

Claims carried over from the AfriPlay wiki are `🔶 LIKELY` for WONA until re-checked against `econetzw`.
